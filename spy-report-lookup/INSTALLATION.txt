Islandking Spy Report Lookup — Installationsanleitung (für Einsteiger)
========================================================================

WAS DAS IST
Ein kleines Zusatz-Fenster, das automatisch auf jeder islandking.ch-Seite
erscheint, mit zwei Reitern: "Spionage" (Bericht zu einem Spielernamen
suchen) und "Flotte" (deine eigene Flotte auflisten) — beides fertig
formatiert zum Kopieren, z.B. für Discord.

Dafür brauchst du die kostenlose Browser-Erweiterung "Tampermonkey" (einmal
installieren, danach läuft alles automatisch — kein Lesezeichen-Klicken
mehr nötig).


SCHRITT-FÜR-SCHRITT (Chrome / Edge / Firefox)

1. Tampermonkey installieren
   Im Chrome Web Store bzw. Firefox Add-ons "Tampermonkey" suchen und
   installieren (offizielle Erweiterung von tampermonkey.net).

2. Neues Skript anlegen
   Auf das Tampermonkey-Symbol oben im Browser klicken → "Dashboard" →
   "Neues Skript erstellen" (das "+"-Symbol).
   Es öffnet sich ein Editor mit etwas Beispiel-Code.

3. Code einfügen
   Öffne die Datei "userscript.js" (liegt im selben Ordner wie diese
   Anleitung) z.B. mit dem Windows-Editor (Notepad).
   Markiere darin ALLES (Strg + A) und kopiere es (Strg + C).
   Im Tampermonkey-Editor: den kompletten Beispiel-Code markieren und
   löschen (Strg + A, dann Entf), dann den kopierten Text einfügen
   (Strg + V).

4. Speichern
   Strg + S drücken oder auf das Speichern-Symbol klicken. Fertig.


BENUTZUNG

1. Geh auf islandking.ch und logg dich ein, falls nötig.
   → Das Lookup-Fenster erscheint automatisch, meist rechts.
2. Reiter "Spionage": Benutzernamen eintragen (Enter drückt auch den
   Knopf), auf "Bericht auslesen" klicken.
   → Unten erscheint der formatierte Bericht.
3. Reiter "Flotte": auf "Flotte auslesen" klicken.
   → Unten erscheint deine Flotte (Schiffe + Soldaten).
4. Auf "In die Zwischenablage kopieren" klicken, dann z.B. in Discord
   einfügen (Strg + V).
5. Auf die Überschrift klicken klappt das Fenster ein/aus.


WENN ETWAS NICHT KLAPPT

• Das Fenster erscheint nicht
  → Du bist wahrscheinlich nicht auf islandking.ch, oder Tampermonkey ist
    für diese Seite deaktiviert (Tampermonkey-Symbol anklicken und
    pruefen, dass das Skript aktiv ist).

• "Kein Spionagebericht für ... gefunden"
  → Es liegt (noch) kein gespeicherter Bericht zu diesem Namen vor —
    erst muss jemand die Zielinsel bespäht haben.

• "Session abgelaufen (401)"
  → Die Seite lädt automatisch neu.

• Eine neue Version ist verfügbar
  → Tampermonkey bietet Updates automatisch an, sobald sich die
    Versionsnummer im Skript erhöht — einfach im Tampermonkey-Dashboard
    bestätigen. Alternativ: das ↻-Symbol im Panel-Header prüft manuell.


Der Titel oben im Fenster ist ein-/ausklappbar (drauf klicken — bleibt
immer sichtbar, darunter angedockte Fenster rücken automatisch nach)
und hat rechts oben ein ⇄-Symbol zum Seitenwechsel (links/rechts
andocken). Beide Einstellungen merkt sich der Browser über Reloads
hinweg.
